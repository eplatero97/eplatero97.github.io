# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

Personal deep learning / ML blog at **https://eplatero97.github.io**, built with Astro 5 and deployed to GitHub Pages via GitHub Actions. Posts are Markdown files with KaTeX math and interactive Plotly/HiPlot visualizations embedded as iframes.

## Dev Commands

```bash
npm install             # install dependencies
npm run dev             # dev server at http://localhost:4321
npm run build           # build to dist/
npm run preview         # preview production build locally
```

## Architecture

**Content:** Posts live in `src/content/blog/` as `.md` files. The collection schema is in `src/content/config.ts` — required fields are `title` and `pubDate`; `category` and `tags` are optional.

**Routing:** `src/pages/blog/[...slug].astro` generates one page per post. The slug strips `.md` from `post.id`.

**Layouts:** `src/layouts/Base.astro` is the HTML shell (nav, footer, global CSS). `src/layouts/BlogPost.astro` wraps post content with a header (title, date, tags).

**Styles:** Single file at `src/styles/global.css`, imported via `<style is:global>` in `Base.astro`. All prose content is scoped under the `.prose` class.

**Assets:** Everything in `public/assets/` is served at `/assets/`. Interactive visualization HTML files are in sub-folders (`html/`, `linear/`, `logistic/`, `relu/`) and embedded in posts as `<iframe src="/assets/...">`. Source images are in `public/assets/images/`.

**Math:** KaTeX via `remark-math` + `rehype-katex`. Use `$$...$$` for display math and `$...$` for inline math in posts.

**Code highlighting:** Shiki with `one-dark-pro` theme, configured in `astro.config.mjs`.

**Deploy:** Push to `main` → GitHub Actions builds and deploys via `@astrojs/sitemap` + `actions/deploy-pages`. Workflow at `.github/workflows/deploy.yml`. GitHub Pages must be set to deploy from **GitHub Actions** (not from a branch) in repo settings.

## Adding a Post

Create `src/content/blog/my-post-slug.md` with:

```markdown
---
title: "My Post Title"
pubDate: YYYY-MM-DD
category: "DL"
tags: ["dl"]
---
```

Interactive visualizations (`.html` files generated by `utils/graphs.py`) go in `public/assets/<topic>/` and are embedded with:
```html
<iframe src="/assets/<topic>/file.html" width="100%" height="500px"></iframe>
```

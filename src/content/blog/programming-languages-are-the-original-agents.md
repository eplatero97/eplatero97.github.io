# Programming Languages Are the Original Agents

Before AI agents, we had another kind of agent: programming languages.

Strange as that sounds, the two share the same basic flow. You give it a prompt, or an instruction, and it — hopefully — does what you asked. That's true whether you're typing `git commit -m "fix bug"` or asking Claude to fix the bug for you. Both are systems built to take instructions and act on them.

What sets them apart isn't the flow. It's the interface, and the capabilities.

## Interface

To talk to an AI, you need to know English. Or whatever language it supports. That's it. Compare that to programming languages, which are picky to the point of breaking over a missing semicolon. But understanding natural language is just the entry fee for an AI agent. The magical part is what happens after it understands you.

## Capabilities

That's where capability comes in — and it's measured by how well a task actually gets done. Coding, summarizing, answering questions, writing stories: AI agents are remarkable for how versatile they are across tasks that are well-defined or vague, precise or hand-wavy. Programming languages don't have that luxury. They demand a specific syntax, and they demand that you, the human, already know exactly what you want.

So does that mean we ditch programming languages and agentify everything? No. Some problems are well-defined enough that there's only one right answer — compute the total, calculate payroll, count the votes — and for those, an agent's best guess isn't good enough, no matter how good agents get. We still need the predictability that only a formal language can give: a fixed grammar, deterministic semantics, no sampling, no "usually." Ask Python what 2 + "2" means and it won't guess — it throws a TypeError, every single time, on every machine.

## The Relationship

What I'm actually arguing is narrower: programming languages have become a tool — and specifically, a tool for agents. They used to be something humans operated directly. Now they're something agents call on our behalf, the same way a program calls a function: agent as client, language as server, request in, deterministic result out.

That reframing matters because it means programming languages aren't dying — they're being repositioned. We didn't kill programming. We abstracted it.
